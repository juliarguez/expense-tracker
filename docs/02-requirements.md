# BALTRA – Project Requirements

## Introduction

This document describes the main requirements for the first version of BALTRA.

The objective is to define the main features of the application before starting the development process. These requirements will be used as a guide throughout the project.

---

# Functional Requirements

The application must provide the following functionalities:

| ID | Requirement |
|----|-------------|
| FR-01 | Users can create an account. |
| FR-02 | Users can log in and log out securely. |
| FR-03 | Users can create new expenses. |
| FR-04 | Users can edit existing expenses. |
| FR-05 | Users can delete expenses. |
| FR-06 | Users can create custom categories. |
| FR-07 | Users can edit and delete categories. |
| FR-08 | Users can filter expenses by category and date. |
| FR-09 | Users can view a dashboard with spending summaries. |
| FR-10 | Users can export their expenses to a CSV file. |

---

# Non-Functional Requirements

The application should also meet the following quality requirements:

| ID | Requirement |
|----|-------------|
| NFR-01 | The application should have a clean and intuitive user interface. |
| NFR-02 | The application should be responsive and work on different screen sizes. |
| NFR-03 | User passwords must be stored securely. |
| NFR-04 | Users should only be able to access their own data. |
| NFR-05 | The application should provide a good user experience with fast loading times. |

---

# User Stories

- As a user, I want to create an account so that I can save my personal expenses.
- As a user, I want to log in so that I can access my information securely.
- As a user, I want to add a new expense so that I can keep track of my spending.
- As a user, I want to edit an expense so that I can correct mistakes.
- As a user, I want to delete an expense so that I can remove incorrect information.
- As a user, I want to filter my expenses so that I can find specific transactions more easily.
- As a user, I want to view charts and summaries so that I can better understand my spending habits.
- As a user, I want to export my expenses to a CSV file so that I can use the data outside the application.

---

# Out of Scope

The following features will not be included in version 1.0:

- AI-powered recommendations
- Budget planning
- Mobile application
- Bank account synchronization
- Multi-currency support
- Notifications
